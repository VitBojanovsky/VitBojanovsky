I'm a software developer and systems engineer with a strong interest in low-level programming, server infrastructure, and embedded hardware. I enjoy working across the full stack — from bare-metal microcontrollers to web backends to 3D-printed enclosures.

Outside of engineering, I'm a licensed glider pilot working toward my PPL and eventually CPL. Flying has sharpened my ability to think methodically under pressure and make sound decisions with incomplete information — qualities I bring to every project.
